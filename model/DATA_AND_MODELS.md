# Происхождение данных и моделей

## Данные организаторов

| Файл в пакете | Исходное имя | SHA256 |
|---|---|---|
| data/train.csv | train_dataset.csv | a75e530d0fb51581ad6800f84b3875233778801491f02236917862faf9b424ec |
| data/test_features.csv | test_features (1)(1).csv | f7ba087818175ea644fc9fe652c6a3874b5bfcde7df197d3e7541cb95876f855 |

Оба файла предоставлены пользователем как материалы организаторов. Они сохранены побайтно. Скрытые контрольные ответы не получены. Устаревший test, прежние submissions и производные целевые поля организаторов не включены в признаки.

Глобальное обучение использует только видимые train-цели. Видимые значения нового test используются как контекст восстановления. Геометрии AOI не предоставлены; внешние спутниковые изображения не загружались и не использовались в финальном fit.

## Реально использованные библиотеки и модельные веса

| Компонент | Использование | Источник / лицензия |
|---|---|---|
| CatBoost 1.2.10 | Обучен на данных организаторов; классификатор источника и три спутниковых регрессора в финальном ансамбле | [CatBoost](https://github.com/catboost/catboost), Apache-2.0 |
| LightGBM 4.7.0 | Два обученных регрессора в финальной смеси | [LightGBM](https://github.com/microsoft/LightGBM), MIT |
| TabICL 2.1.1 | Проверен как внешний DL-кандидат; не вошёл в рекомендованную CPU-смесь | [TabICL](https://github.com/soda-inria/tabicl), BSD-3-Clause для основного кода |
| tabicl-regressor-v2-20260212.ckpt | Публичные предобученные веса; локальный эксперимент 4k/2, отдельный Kaggle-кандидат 12k/4 | [jingang/TabICL](https://huggingface.co/jingang/TabICL), BSD-3-Clause по model card |

SHA256 использованного TabICL checkpoint, список отобранных признаков и индексы контекста сохранены в `reports/initial_experiment/tabicl_fold_*_manifest.json`. В архив не включены четыре лишние копии невыбранных CV-весов. При Kaggle-запуске фиксируется хеш фактически скачанного checkpoint.

TabPFN-3, TimesFM-3, Chronos-2, Mitra, SAITS и Prithvi изучены по первоисточникам. Их веса и предсказания не использованы в готовом submission. Оценка применимости и ссылки находятся в `RESEARCH.md`.

Для последующей передачи результата сохраняйте эту таблицу и фактические manifests. После изменения состава ансамбля обновите перечень: исследованный метод и использованный метод — разные статусы.
