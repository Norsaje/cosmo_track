# Расхождения документов и фактических данных

Источник: визуально прочитаны все 19 страниц `docs/case_doc.pdf`, формула также
сверена с `docs/criteria.pdf`, стр. 2. Исходные CSV не изменяются.

| Утверждение | Факт | Принятое решение |
|---|---|---|
| case_doc, стр. 11: train содержит 99 955 строк с известным primary_ndvi | 99 955 строк, но только 30 520 конечных target; 69 435 естественных пропусков | Наблюдением является только finite target |
| case_doc, стр. 11–12: имя test private_features.csv | Фактическое имя data/test_data.csv | CLI принимает явный путь; schema проверяется по фактическим столбцам |
| case_doc, стр. 7: primary_ndvi назван «согласованным» рядом | Задание определяет сырой ряд иерархии S2 → Landsat → MODIS | Конкурсная цель сохраняется; harmonization только в отдельном продуктовом поле |
| В маске указаны status и ndvi_zscore | Эти столбцы есть только в train | Псевдомаска скрывает их при наличии; feature builder никогда их не читает |
| Типичный диапазон NDVI [-1, 1] | Конечный train target до −2.1303786081; видимый test до 1.8428536898 | Target не clip; физические флаги отдельно; фильтрация только sensor/weather context |
| Разбиение train/test может восприниматься как random rows | 78 test polygons, 39 общих с train; 2648/3112 gaps на новых полигонах | CV-A приближает долю новых полигонов, CV-B полностью исключает их из fit/priors |
| CV может буквально повторить test годы | 925/3112 test gaps в 2025, train заканчивается в 2024 | CV-A сопоставляет эпоху доступности датчиков, CV-C отдельно проверяет строгий прогноз; 2025 остаётся сдвигом распределения |

Контрольные числа: train `(99955, 21)`, 39 полигонов, 2010-04-01–2024-10-30;
test `(57185, 20)`, 78 полигонов, 2010-04-01–2025-10-30, 17 641 видимых
finite target, 3 112 synthetic gaps, 36 432 естественных пропуска. Дубликатов
ключей и пересечений train/test по polygon+date нет. На test gaps все 17
числовых динамических/вычисляемых полей отсутствуют. Только 464 gaps относятся
к знакомым полигонам (14.91%).

Серия gaps определяется последовательными скрытыми потенциальными наблюдениями
внутри polygon/year, с пропуском естественно пустых строк дневной сетки.
В CV-D остаётся ровно один конечный target-сосед >15 дней слева. Остальной
контекст этого полигона цензурирован; оценка помечена как стресс-тест.
Истинный source у настоящих test gaps неизвестен: используется только прокси
из видимых строк, и это ограничение сохраняется в отчёте распределений.

Автоматические сводки, missingness, SHA256 и source hierarchy:
`artifacts/ml/baseline_v1/{data_summary,test_mask_profile,source_hierarchy}.json`.
GapScore = `round(30 * max(0, 1 - RMSE / 0.10), 2)`, без иных нормировок.
