# Визуальный R&D review реальных anomaly candidates

Алгоритм: `robust-loyo-events-0.1.1`. Вход: `train_dataset.csv`, SHA256 указан
в `summary.json`. Fit/reference: 2010–2023, query: 2024. Проанализированы 39
полигонов, 6 892 строки, 2 848 наблюдений. Ни supplied status/zscore, ни готовая
CSV climatology не использованы как labels/features.

Это exploratory анализ аномалий с историческим reference, **не DL OOF** и не
размеченный anomaly benchmark. Пороги оставлены исходными; по этим случаям
threshold tuning не выполнялся. Выбор графиков автоматический: три наибольших
event score и три других polygon с большим числом source-risk/low-confidence events.
Все шесть PNG просмотрены агентом; экспертное принятие ML/Backend ещё pending.

## Диагностика гармонизации

Калибровка обучена на данных до 2024. Ниже ошибки относительно S2 только на
синхронных допустимых парах 2024; это **не** RMSE конкурсного primary_ndvi.

| Источник | Пар | MAE raw | MAE harmonized | RMSE raw | RMSE harmonized |
|---|---:|---:|---:|---:|---:|
| Landsat | 319 | 0.05338 | 0.02655 | 0.06395 | 0.04207 |
| MODIS | 139 | 0.09949 | 0.06634 | 0.12964 | 0.09490 |

Сохранены точные значения и median bias в `sensor_alignment.csv`. Mapping
снижает несогласованность на этом годе, но остаточная ошибка MODIS заметна.
Это поддерживает использование отдельной harmonized шкалы для anomaly;
не доказывает улучшение submission, unseen generalization или calibrated coverage.
Следует повторить диагностику на официальных train folds после C-03.

## Найденные дефекты и исправления

1. Пустая календарная строка с source=unknown раньше считалась сменой датчика.
   Теперь сравнение идёт с предыдущим доступным измерением. Добавлена проверка
   инвариантности event к вставке пустых календарных строк.
2. Естественные NaN ошибочно давали warning о неуверенной реконструкции.
   Теперь warning относится только к конечным реконструированным значениям.
3. Global/crop/year summaries повторно считались для каждого polygon/date.
   Добавлен cache, который полностью очищается при fit; расчёт `analyze()`
   возвращает points и events за один проход. LOYO semantics не изменены.

## Runtime и решение

Fit calibration/reference: 2.32 s. Суммарный скоринг 39 полигонов: 36.81 s CPU,
включая первое заполнение cache; часть прогона совпала с unit tests.
Это диагностический замер, не SLA benchmark. Первый polygon 3.40 s,
последующие в этом прогоне примерно 0.25–1.97 s.

Всего 91 candidate event, из них 12 algorithmic critical. Precision, recall,
false alerts per real season **не определены** без ground truth. 91/39 нельзя
называть частотой ложных тревог: истинность событий не размечена.

Решение: C-09 пригоден для интеграционного review с обязательными warnings,
source provenance и осторожной интерпретацией. Не заявлять clinical/agronomic
certainty. Следующие ценные проверки: phenology alignment без подавления реального
стресса, влияние севооборота и reference hierarchy, QA из live provider,
независимый multisensor evidence и ручной экспертный разбор. Эти улучшения должны
быть проверены отдельно, а не приняты после визуальной подгонки этого года.

Воспроизведение:

```powershell
$env:PYTHONPATH='src'
python -m veg_recovery.dl.real_anomaly_cases --year 2024 --output reports/anomaly_cases/real_2024
```
